# Lingua

Tes singkat untuk memetakan kemampuan bahasa Inggris dan latihan menuju TOEFL serta IELTS. Hasil langsung keluar, tanpa perlu membuat akun.

Versi yang sedang tayang: [testbahasainggris.vercel.app](https://testbahasainggris.vercel.app)

## Isi situs

- Tes penempatan level, dengan perkiraan CEFR dari A1 sampai C1
- Latihan mini TOEFL ITP dan IELTS Academic
- Latihan panjang: TOEFL ITP (140 soal) dan IELTS Academic (listening, reading, writing, speaking)
- Pembahasan jawaban setelah sesi selesai

Hasil di situs ini adalah latihan, bukan skor resmi TOEFL, IELTS, atau sertifikat CEFR.

## Menjalankan

Buka `index.html` di peramban. Seluruh situs ada di satu berkas.

## Teknologi

HTML, CSS, dan JavaScript.
